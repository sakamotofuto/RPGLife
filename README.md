# RPGLife

現実の行動を記録して、キャラクターの成長とボス攻略につなげる日本語Webアプリの初期版。

## 開発

Node.js 22.12以上（検証環境：24.19.0）が必要です。

```sh
cd /workspace/RPGLife
npm ci --cache /workspace/.npm
npm run dev -- --port 5173
```

```sh
npm test
npm run build
```

## 遊び方

1. 名前と目標を登録。
2. 用意された5種のクエストから現実で行う挑戦を選ぶ。
3. 実行後に達成度・難しさ・任意のメモを記録。
4. XPの獲得と同時にボスへ攻撃。累計200 XPで討伐し、称号を獲得。
5. ブラウザを開き直して再開。履歴から記録を取り消すことも可能。

## 計画書から採用した仮の仕様

元資料は未記入の「現実世界をRPGにするゲーム開発計画書」です。以下は初期版を動かすための実装上の仮定で、合意済みの最終仕様ではありません。

- 対象：PC・スマートフォンのブラウザ。ViteとJavaScriptで実装。
- 名前と目標を1つ登録。目標は変更可能。現在のクエストは目標に応じた自動生成ではなく固定候補。
- XP：散歩30、本25、集中40、片づけ20、休息15。部分達成は半分（四捨五入）。
- 100 XPごとにレベルアップ。ボスHPは200、ダメージは獲得XPと同じ。討伐報酬は称号「最初の一歩」。ボスは初期版では1体。
- 報酬はクエストごとにブラウザの現地日付で1日1回。取り消したクエストは再記録可能。時刻の改変や複数端末での不正対策は対象外。
- 難しさは振り返り用に記録し、XPには影響しない。未達成や休息日による減点はなし。
- 取り消し時は履歴からXP・レベル・ボスHP・称号を再計算。
- localStorageで端末内保存。ログイン・クラウド同期なし。設定からJSONを書き出せる（現段階ではインポートなし）。ブラウザのデータ削除で記録も失われる。
- 保留：AI提案、5種の能力値、SNS、協力、3D、装備、位置情報、複数ボス。
- 外部API、フォント配信、画像配信への依存なし。イラストはCSSで描画。

## 確認範囲

`npm test` はXP・部分達成・二重報酬防止・レベル・ボス討伐・保存復元・取り消し・休息時の保持を検証します。実機利用テストと利用者による楽しさの評価は別途必要です。
